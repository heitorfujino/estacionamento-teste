# `#Estacionamento` 

```
O programa funciona que nem um estacionamento, guardando dados de entrada e
saída, informações do carro/moto, com desconto para quem faz viagens de uber,
ele resolve o grande problema de achar vaga de estacionamento no centro
principalmente.
```
